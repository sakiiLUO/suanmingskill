## はじめに、ここを見てください (◕‿◕)

これは AI Agent 向けの **skill** です：`SKILL.md` が「どう話すか」を担い、`references/` はすぐ引ける小抄（チートシート）、`scripts/` は実際に盤を算出する Python です。

それは怖くもなければ、怪しくもありません：

- まず淡々と**排盤**（はいばん＝命式を組み立てること。真太陽時、夏時間、晩子時、節気の境界まで処理します）
- 次に「**盤面の事実 → 境界と不確実性 → 根拠付きの仮説 2〜3 本 → 自分で検証できる小さな一歩**」を返します
- 最後にこう伝えます：**これは解釈の枠組みであって、予測ではありません。** 決めるのはあなた自身です (｡･ω･｡)ﾉ♡

> 関係における「続けるべきか、この一言にどう返すか」は [狗头军师](https://github.com/shengjidaguai-china/goutoujunshi) に任せられますが、この skill は**デフォルトで単体で使えます**。なくても大丈夫です。

## どう返してくるか ✨

```text
盤面の事実：真太陽時 1995-08-17 14:26、四柱（しちゅう）は 乙亥 甲申 庚辰 癸未、日主は庚金、月令は申金；
          現在は辛巳の大運（だいうん＝10 年ごとの運気の区切り、2018–2027）を運行中、2026 年の流年は丙午。
境界と不確実性：出生時刻は未時と申時の境界から離れているため、時柱は安定；1986–1991 年の夏時間には該当しない。
仮説（断定ではありません）：日主が庚金、月令が申金なら、ふつう「まず自分で抱え込み、弱みを見せたがらない」と解釈されます。
逆の可能性：幼い頃から独立を求められて身についた習慣で、天性ではないかもしれません。
検証できる小さな一歩：直近のプレッシャーのかかった出来事を三つ思い出し、あなたはまず人に相談したか、まず自分で消化したか；
              すべて自分で消化していたなら、この線はよりあなたに近いと言えます。
以上は解釈の枠組みであり、予測ではありません (・∀・)
```

見えましたか？**「結論」の一つひとつに根拠、逆の可能性、そして検証できる行動が添えられています**——「運命づけられています」の二言は出てきません (๑•̀ㅂ•́)و✧

## 何を相談できるか ⭐

| 相談したいこと | 話してくれること | はっきり避けること |
| --- | --- | --- |
| 性格、行動パターン | 根拠付きの仮説 2〜3 本 | 身強身弱、用神喜忌の断定 |
| 仕事、キャリアの方向 | 仕事のスタイル、組織の形、時間の窓 | 具体的な業界・企業、投資対象 |
| 学業、試験 | 学び方、プレッシャーのリズム | 点数、合格、採用の確率 |
| 体調、不安の状態 | ストレス反応、生活リズム、相談先 | 診断、病気の予測、服薬の助言 |
| 親、子ども、家族 | 家族の中での役割、境界線の課題 | 第三者への寿命・健康・離婚の話 |
| 恋愛、相性 | 7 つの次元 + 根拠 | 「うまくいくか」の判定 |
| 大運流年、いつ | 時間の窓の仮説 + 観察のサイン | 具体的な時期、吉凶の断言 |
| 「これって科学なの？」 | 古典の出典 + A/B/C/D の証拠等級 | 経験則を科学的結論に装うこと |

## 経典の一文も返せます (｡•̀ᴗ-)✧

ときには、より多くの分析ではなく、重みのある一文だけが必要なこともあります。『道徳経』『論語』『心経』『聖書』（和合本）から一句を選び、やさしい現代語の説明を添え、あなたの話に戻します：

```text
『道徳経』第二十三章：「飄風は朝を終えず、驟雨は日を終えず。」
意味は：どれほど激しい風雨も、一日中は続きません。
あなたのこの件に置き換えると——つらさには期限があります。ただしその期限は自分からは来ません。
（この一句は予言ではありません。使わなくてもかまいません。）
```

ルールも固く定めています：**一度に一句、出典を必ず明記、改宗を勧めない、地獄・終末・報いで脅さない、経文を予測の根拠にしない**。中国語版『クルアーン』の翻訳はまだ著作権期間内なので、大意のみを伝えて注記します (｀・ω・´)
## やらないこと 🚫

- 生死、寿命、病気の診断、災厄、胎児の性別、訴訟の勝敗、投資対象、試験の点数は占いません
- 夫剋（おっとがめ）・妻剋、命が硬い/安い、童子命といった決めつけはせず、人の「運気を変える」ことや、お祓いの名目で金銭を取ることもしません
- 同意なしに、他人の健康・寿命・プライバシーを分析しません
- 未成年の合婚や恋愛の合盤はしません
- 自傷、家庭内暴力、脅迫に直面したら、**命理解読を直ちに中止**し、まず安全を確認します

「送信前のセルフチェック機能」も内蔵しています。「運命づけられています／必ず〜になります／夫剋／血光／開光／合盤 87 点」といった表現が回答に出ると、止められて書き換えられます (｀・ω・´)ｼ

## 使ってみる (ﾉ´ヮ`)ﾉ*: ･ﾟ

```bash
# 排盤（brief モードは回答にそのまま貼るのに向いています）
python scripts/paipan.py --birth "1995-08-17 14:30" --gender male --city 杭州 --format brief

# 合盤（二人の関わり方を見たいとき。合盤＝二人の命式を並べて相性を見ること）
python scripts/paipan.py --birth "1995-08-17 14:30" --gender male   --city 杭州 --save .suanming/a.json
python scripts/paipan.py --birth "1996-03-08 09:15" --gender female --city 北京 --save .suanming/b.json
python scripts/hepan.py --a-json .suanming/a.json --b-json .suanming/b.json

# 回答を書き終えたらまずセルフチェック、言い過ぎを防ぎます
python scripts/lint_reply.py --file draft.md
```

あとは会話の中で *「私の命を占って」*、*「どんな仕事が向いてる？」*、*「私たち相性は？」* と言うだけです～

## 🔍 この層が信頼できる理由

冗談は冗談として、**盤を出すこの層は本気です**：

| 層 | やり方 | 検証 |
| --- | --- | --- |
| 暦算 | `lunar-python`（MIT）+ 自前の真太陽時／夏時間／晩子時ルール | テスト 53 件；**GB/T 33661-2017 干支紀日のアンカー**（1949-10-01 = 甲子日）を含む |
| 排盤 | 真太陽時（経度差 + 均時差）、1986–1991 年の夏時間、立春／節気の境界警告 | 立春での柱の切り替え、夏時間の初日と最終日、晩子時の二つの扱い |
| 発話 | 回答セルフチェッカー：20+ 件の越境ルール + 構造チェック | 対話のレッドチーム 34 件、すべて期待どおり |
| 引用 | 古典は原文を照合した 8 条のみを D 級として収録；実証研究は A/B/C | `references/11`、`references/12` |

```bash
python -m unittest discover -s tests -v   # 53 tests
python scripts/validate_skill.py           # 構造/引用/ライセンス/禁止内容
python scripts/eval_dialogue.py            # レッドチーム 34 件
```

## よくある小さな質問 (・∀・)

**Q：ネット接続は必要？**
いいえ。依存は `vendor/` に同梱済みで、排盤は完全にローカルです。

**Q：お金はかかる？**
かかりません。MIT です。自由に使えます。名前を載せてくれれば十分です。

**Q：誕生日はアップロードされる？**
されません。計算はすべてローカルです。記録を残すにはあなたの明確な同意（`--consent`）が必要で、いつでも確認・削除できます。

**Q：紫微斗数 / 六爻 / タロットは占える？**
今はまだありません。紫微はロードマップにあります（MIT の iztro を使い、Node の子プロセスで動かす予定）。PR 歓迎です (๑•̀ㅂ•́)و✧

**Q：「あなたは運命づけられています……」と急に言われることは？**
ありません。`scripts/lint_reply.py` が止め、`SKILL.md` にも決定論的な言い回しの禁止が明記されています。

**Q：当たるの？**
それ自体がこう答えます：*「自分は的中するとは言いません。盤面は計算されたもの、解釈は仮説です。当たるかどうかは、仮説の中からあなたに役立つ部分を選べるかどうかで決まります。」* (´･ω･`)
