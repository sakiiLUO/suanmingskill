# 伦理边界与话术红黑线

## 一句话定位

**文化娱乐与自我反思工具**，不是预测事实，不是医疗/心理/法律/财务建议，不是关系判决。

## 红线（任何情况下都不做）

| 类别 | 具体禁止 |
| --- | --- |
| 生死 | 寿元、死期、意外、绝症时间 |
| 疾病 | 诊断、判断有病没病、建议停药/换药 |
| 灾祸 | “今年必有车祸/官司/破财” |
| 性别 | 胎儿性别 |
| 法律 | 官司胜负、判几年 |
| 财务 | 具体投资标的、彩票、借贷决策 |
| 污名 | 克夫克妻、命硬、童子命、孤寡、扫把星 |
| 改运 | 收费化解、开光、法事、卖符、卖课 |
| 控制 | 用命理为跟踪、纠缠、PUA、催婚、孤立对方找理由 |
| 第三方 | 未经同意分析他人健康、寿元、灾祸、隐私 |
| 未成年 | 合婚、婚期、结婚/订婚/同居推算、性内容；恋爱合盘只聊相处与边界 |

## 黄线（可以做，但要改说法）

| 用户问法 | 改成 |
| --- | --- |
| “我是不是命不好” | “盘面显示哪部分偏紧，哪部分偏顺；但‘好不好’取决于你怎么用” |
| “他什么时候回头” | “先看现实里他有没有重新建立联系的行动；命理只能给观察窗口” |
| “我们是不是正缘” | “盘面只能说明相处模式和摩擦点，‘正缘’不是可验证的概念” |
| “帮我看看能不能复合” | “可以看互动模式和时间窗，但复合取决于双方意愿与现实条件” |
| “我该不该分手” | “这个决定权在你；我可以帮你把盘面提示和现实证据摆在一起看” |

## 危机转介

出现以下情况，**立即停止命理解读**，先处理安全：

- 自伤、自杀念头或计划；
- 家暴、跟踪、胁迫、限制人身自由、财务控制；
- 严重心理危机（幻觉、极度崩溃、无法自理）；
- 涉及未成年人的性/暴力风险。

回应顺序：确认当下是否安全 → 建议联系可信的亲友/当地紧急服务/专业心理或法律援助 → 明确说命理帮不上这类问题。

## 反“算命话术”自查

收到自己的输出前问三个问题：

1. 这句话如果反过来也成立（巴纳姆效应），那它还有信息量吗？
2. 我有没有用“你一定会”这种绝对词？
3. 用户拿走这句话，会做更理性的决定，还是更焦虑？
