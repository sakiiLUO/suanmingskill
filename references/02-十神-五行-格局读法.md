# 十神、五行、格局怎么讲成人话

## 先讲清边界

本 skill 只输出“结构提示”，不输出**旺衰喜忌、用神、格局高低、流年吉凶**这类需要完整师承与大量校正的专业定论。原因：这些结论依赖流派、古籍版本和个人经验，且极易被用户当成命运判决。

可以说的：日主是什么、月令给了什么环境、哪些十神出现得多、五行分布哪里偏。
不可以说的：“你身弱不担财”“你格局太低”“今年必破财”。

## 十神速查（只作翻译用）

| 十神 | 关系 | 人话版本 | 常见误用 |
| --- | --- | --- | --- |
| 比肩/劫财 | 同我 | 自我、同辈、竞争与合伙 | “比劫旺必克妻”——标签化 |
| 食神/伤官 | 我生 | 表达、创造、输出、审美 | “伤官见官必离婚”——宿命论 |
| 正财/偏财 | 我克 | 掌控资源、务实、结果导向 | “财多身弱必穷”——吓人 |
| 正官/七杀 | 克我 | 规则、责任、压力、权威关系 | “七杀无制必凶”——恐吓 |
| 正印/偏印 | 生我 | 支持、学习、被照顾、安全感 | “枭神夺食必灾”——宿命论 |

**用法**：把十神当成“行为倾向的词汇”，不是“命运判词”。例：
- 可以说：“你盘里伤官出现得多，可能比较需要表达空间，被压着会难受。”
- 不能说：“你伤官旺，注定婚姻不顺。”

## 五行怎么讲

脚本给的是**加权计数**（天干 1.0、藏干本气 1.0 / 中气 0.5 / 余气 0.3）。

- 可以讨论“哪类元素偏多/偏少”，以及它对应的行为语言（木=生长扩张、火=表达热度、土=稳定承载、金=规则边界、水=流动适应）。
- 不能说“缺什么就要补什么”“用什么颜色/方位改运”——这是消费陷阱的入口。
- 用户问“我是不是五行缺X”，回答：计数上偏少，但这不等于需要补，也不等于缺了就不好。

## 日主与月令

- `day_master` 给出日主天干、五行、阴阳，以及月支本气与日主的关系（同气 / 得生 / 被克泄）。
- 这是**讨论起点**：得令的人往往更容易按本性行事；失令的人往往更早学会调整。
- 不要升级成“身强身弱”。要谈强弱，谈**具体行为**：遇到冲突是先扛还是先说、被否定后是撤还是顶。

## 输出模板（假设层）

```text
盘面：日主庚金，月令申金（同气），天干透甲木偏财、乙木正财。
假设（可能，不是定论）：你对“值不值得投入”比较敏感，习惯先算清成本再行动。
反向可能：也可能只是这几年在做生意/管钱，训练出来的习惯。
验证方式：回想最近三次花钱或投入精力的决定，是先算账还是一时冲动？
```

## 禁止清单

- 不断寿元、疾病、灾祸、官司、胎儿性别。
- 不使用“克夫/克妻/命硬/童子命/孤辰寡宿注定孤独”等污名标签。
- 不承诺“化解”“改运”“开光”效果。
- 不引用无法核实的“某某大师说”。
