# 排盘规则与真太阳时

## 四柱怎么来的

| 柱 | 依据 | 边界 |
| --- | --- | --- |
| 年柱 | 立春为岁首，不是元旦也不是春节 | 立春交节时刻前后换柱 |
| 月柱 | 二十四节气中的“节”（立春、惊蛰、清明…），不是农历月份 | 交节时刻前后换柱 |
| 日柱 | 连续六十甲子，按日推进 | 23:00 后是否换日取决于流派 |
| 时柱 | 两小时一个时辰（子时 23:00–00:59） | 时辰交界 |

## 真太阳时：三个修正量

真太阳时 = 钟表时间 − 夏令时 + 经度差 + 均时差

1. **夏令时**：中国 1986–1991 年实行夏时制（每年 4–9 月，时钟拨快 1 小时）。区间内出生要回拨 60 分钟。
2. **经度差**：每偏离东经 120° 一度，差 4 分钟。北京约 −14 分钟，乌鲁木齐约 −130 分钟（差两个多时辰）。
3. **均时差**：地球公转轨道偏心率造成，全年在 −14 到 +16 分钟之间波动，2 月中约 −14 分、11 月初约 +16 分。

脚本 `solartime.py` 用 NOAA 简化公式算均时差（误差数十秒），对时辰粒度足够。

## 为什么必须做

出生在时辰边界附近时，10–20 分钟的校正就能把时柱（甚至日柱）换掉，而时柱决定子女、晚年、部分性格描述，合盘里也参与日支之外的判断。**不做校正又不说，是最常见的错。**

## 晚子时（23:00–23:59）

- 流派 A（子时换日）：日柱取次日，时柱为子时。
- 流派 B（不换日）：日柱取当天，时柱仍为子时。

本 skill 默认 A（`--late-zi next_day`），并在输出里明说。切换用 `--late-zi same_day`。两种口径的日柱天干不同，十神会整体变，必须告知用户“这里存在口径差异”。

## 闰月与时区

- 农历闰月出生：月柱按节气，不按农历月，脚本已处理；但用户若按“闰月”自我描述，回答时把两者分开讲。
- 海外出生：时区、夏令时规则因国而异，必须让用户确认当地当年是否实行夏令时；脚本 `--tz` 可改时区，`--dst off` 关闭中国夏时制表。

| 输入 | 输出 |

| 1995-08-17 14:30 杭州 男 | 真太阳时 14:26，乙亥 甲申 庚辰 癸未，日主庚金 |

## 历法依据（为什么可以信这一层）

| 项目 | 依据 | 说明 |
| --- | --- | --- |
| 农历编排 | **GB/T 33661-2017《农历的编算和颁行》**（2017-09-01 实施） | 北京时间；朔日为月首；含冬至之月为十一月；两冬至间 13 个月则置闰，取最先出现的无中气之月；冬至后第二个月为岁首 |
| 节气 | 黄道 360° 等分 24 份，**每气相差黄经 15°**（春分 0°、夏至 90°、秋分 180°、冬至 270°） | 每月必有中气，无中气之月即闰月 |
| 干支纪日 | 国标参照 **1949-10-01 为甲子日** | 本项目已加回归测试：该日日柱必须为甲子 |
| 干支纪年 | 国标参照 1984-02-02 起甲子年（农历正月初一为界） | **注意**：八字排盘按**立春**换年，与农历纪年不同，两者不要混用 |
| 真太阳时 | 经度差 + 均时差（NOAA Solar Calculator 算法，简化公式误差数十秒） | 时区、经度、夏令时必须显式传入 |
| 1986–1991 夏令时 | 每年 4 月中旬第一个星期日 02:00 起，9 月中旬第一个星期日 02:00 止，拨快 1 小时；1992 年暂停 | 逐年具体日期建议用 IANA tzdata `Rule PRC` 核对；本 skill 内置常用 tzdata 值 |

**已知边界**：均时差为简化公式，不做分钟级天文校验；海外出生的时区与夏令时规则需用户提供当地信息。
