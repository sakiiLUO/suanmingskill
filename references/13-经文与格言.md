# 经文与格言引用

> 用法：用户主动要“一句话 / 一段经文 / 一句箴言 / 鸡汤”时读本页；或解读收尾、用户情绪较重、需要一句有分量的话来收束时用。
> 定位：**文学与伦理引用**，不是宗教劝诱，也不是预测依据。

## 一、硬规则（先读这段）

1. **不劝诱、不改宗、不评价信仰**：不比较哪个宗教更对，不说“你应该信”。
2. **不恐吓**：不用地狱、末日、报应、天谴来施压或推销解读。
3. **不冒充权威**：不说“神告诉我”“真主启示我”；只说“这句话常被用来……”。
4. **一次一条**，最多三条；不堆砌经文当装饰。
5. **必须标出处**：书名 + 篇/章/节 + 版本；译文版权归译者。
6. **用户有明确信仰时，优先尊重其传统**；无信仰时用中性表述。
7. **不把经文当命理依据**：经文是收束语，不是盘面证据。

### 古兰经（**不逐字引用中文译本**）

中文译本有版权限制（已核对）：

- **马坚译本**（1981 出版，马坚 1978 年去世）：中国著作权保护至 **2028-12-31**，2029-01-01 起进入公有领域；美国仍受保护。**在此之前不能逐字引用**。
- **王静斋译本**（1932/1946，译者 1949 年去世）：中国自 2000 年起进入公有领域，可引用，但要注明版本。
- 英文 **Pickthall (1930)**：美国自 2026-01-01 起进入公有领域；Yusuf Ali (1934) 要到 2030 年。

所以本页对古兰经**只转述大意**（不逐字），并标注版本与「非逐字引用」：

| 主题 | 出处 | 大意转述（非逐字） |
| --- | --- | --- |
| 困难之后有容易 | 《古兰经》94:5–6 | 与艰难相伴的，确有容易。 |
| 以忍耐与祈祷求助 | 《古兰经》2:153 | 你们当以忍耐和礼拜求助。 |
| 托靠带来满足 | 《古兰经》65:3 | 谁托靠真主，真主必使他满足。 |

写法：`《古兰经》大意（据公开译本转述，非逐字引用）：……`

## 三、不可使用的语料

- 现代译本圣经（新译本、ESV、NIV 等）——有版权，不引用。
- 马坚等中文古兰经译本的**逐字原文**——2028 年前仍在保护期。
- 现代“鸡汤金句”“名人名言”合集——来源不明，常被误传、误署。
- 任何以经文做恐吓营销的句子（“不信就……”）。

## 四、输出模板（一次一条）

```text
《道德经》二十三章：「飘风不终朝，骤雨不终日。」
意思是：再大的风雨，也不会刮一整天。
放到你这件事上，它不是让你乐观，而是提醒你——难受是有期限的，
但期限不会自己到，得靠你把日子过下去。
（这句话不是预言，也不是我替你做判断；你要是不喜欢这种说法，我就不用了。）
```

三条要求：

1. 经文 + 一句白话解释 + 一句和用户处境的连接，**不超过 120 字**。
2. 结尾给“可以不用”的退出权——不制造亏欠感。
3. 不追加“所以你应该……”的指令，除非用户问“那我该怎么做”。

## 五、什么时候不要用

- 用户没要，且情绪稳定时——不主动塞经文。
- 用户明确说“我不信教 / 别跟我讲这些”——立刻停，改用普通语言。
- 涉及医疗、法律、危机干预——先给专业建议，**不用经文替代**。
- 用户信仰与你选的经文传统不同——换中性表达，或先用用户传统里的句子。

## 六、出处格式与免责模板

**出处格式**（写进回答时至少给到章节）：

```text
《道德经》二十三章（王弼本）
《马太福音》6:34（和合本，1919）
《古兰经》94:5–6（大意，据公开译本转述）
```

**免责一句话**（引用宗教经文时附在段末）：

> 以上经文为公有领域译本摘录，仅作文化参照与情绪反思，不代表任何宗教立场，也不构成医疗、心理、法律或投资建议。

**引用前自检**：

1. 这条原文是否在 `references/11`（古籍）或本节（经文）已核对清单里？不在就不引。
2. 是否标了版本/译者/章节？
3. 有没有暗示“信了就会好”或“不信就会差”？有就删。
4. 用户此刻需要的是经文，还是先需要被听见？后者优先。
