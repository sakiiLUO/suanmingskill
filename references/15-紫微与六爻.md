# 紫微斗数与六爻：怎么用、怎么读、哪里不能越界

> 用户问“帮我排个紫微盘 / 摇一卦 / 六爻看看这件事”时读本页。
> 两者都只是**解释框架**，不预测事实；排盘可以准，结论必须标假设。

## 一、紫微斗数（`scripts/ziwei.py`）

### 排盘

```bash
python scripts/ziwei.py --birth "1995-08-17 14:30" --gender male --city 杭州 --format brief
python scripts/ziwei.py --birth "1995-08-17 14:30" --gender male --city 杭州 --year 2026 --save .suanming/ziwei.json
```

- 引擎：iztro 2.6.3（MIT），已 vendor 到 `vendor/iztro/`，**离线可用**，需要 Node.js 18+。
- 先做真太阳时校正（经度差 + 均时差 + 1986–1991 夏令时），再交给 iztro。
- 23:00 后按 `--late-zi` 处理：`next_day`（默认）转次日早子时，`same_day` 保留晚子时（timeIndex=12，存在流派差异）。

### 怎么读（只讲这四层）

| 层 | 看什么 | 可以讨论 | 不要做 |
| --- | --- | --- | --- |
| 命/身宫 | 命宫主星、身宫落点 | 行为风格与“在意什么” | 断“命好命坏” |
| 十二宫 | 命、夫妻、官禄、财帛、福德、迁移等 | 哪个领域更用力、哪块更紧 | 用宫位断具体事件 |
| 四化 | 生年四化（禄权科忌）落宫 | 注意力和执念在哪 | 把“忌”说成灾祸 |
| 大限/流年 | 当前大限宫位与流年四化 | 阶段性主题、宜复盘不宜冲动 | 给“必升职/必离婚/必破财” |

**读法顺序**：命宫主星 → 身宫 → 四化落宫 → 当前大限 → 流年。每次只讲 1–2 个重点，不背宫位表。

### 已知坑

- 晚子时在农历月末的口径差异（iztro issue #314）：默认已转次日早子，回答里要说明。
- 闰月：iztro 用 `fixLeap`；本项目暂不暴露该开关，遇到闰月出生要声明“口径可能不同”。
- 大限起运按虚岁，不同流派可能差 1 岁；回答里写“按虚岁口径”。
- 2057 年后 iztro 农历数据可能与实历有偏差（issue #309），远期流年只当参考。

## 二、六爻（`scripts/liuyao.py`）

### 起卦

```bash
# 摇卦：自下而上 6 个爻值（6 老阴、7 少阳、8 少阴、9 老阳）
python scripts/liuyao.py --lines 7,8,9,7,6,8 --date "2026-10-31 19:40" --question "这次合作能成吗" --format brief

# 没有铜钱时：时间起卦（梅花式），只作参考
python scripts/liuyao.py --method time --date "2026-10-31 19:40" --question "..."
```

- 纯标准库实现：八卦纳甲、京房八宫世应、六亲、六神、月建、日辰、旬空、变卦；规则表由测试锁定。
- 不做：旺衰打分、应期推断、吉凶评分——这些没有可靠共识，容易变成“大师话术”。

### 怎么读

| 要素 | 含义 | 可以讨论 |
| --- | --- | --- |
| 本卦 / 变卦 | 现状 → 变化方向 | 事情现在的结构和可能的转折 |
| 动爻 | 变化的触发点 | 哪一环最不稳定 |
| 世爻 / 应爻 | 自己 / 对方或所问之事 | 双方位置与主动性 |
| 六亲 | 父母/兄弟/子孙/妻财/官鬼 | 资源、同辈、结果、利益、压力 |
| 月建 / 日辰 / 旬空 | 时间背景 | 现在“有力/无力”的提示（只说倾向） |

**读法顺序**：先看世应 → 再看动爻与变卦 → 最后看六亲落在哪。一次只解读 1–2 个动爻。

### 边界

- 不用于医疗、法律、投资、人身安全决策；不承诺“必成/必败”。
- 同一问题不反复起卦（“摇到好为止”就是自欺）。
- 用户问生死、疾病、官司结果：拒绝，转回现实建议。
- 未成年人的卦：只谈相处与安全，不做婚姻判断。

## 三、三套体系怎么配合

| 用户问 | 先用 | 再看 | 不要 |
| --- | --- | --- | --- |
| 一生结构、性格、长期主题 | 八字（`paipan.py`） | 紫微（十二宫） | 两套结论冲突时硬编一个“都对” |
| 具体一件事的当下状态 | 六爻 | 八字流年 | 用六爻断一辈子 |
| 关系合不合 | 八字合盘 | 紫微夫妻宫 | 用紫微给“正缘时间” |

**冲突处理**：两套说法不一致时，明说“两套体系看的角度不同”，把差异当提问角度，不当成“更深层的真相”。
