# 导读与加载路由

## 这个 skill 的三层

| 层 | 内容 | 是否可复核 |
| --- | --- | --- |
| 计算层 | `scripts/paipan.py`、`scripts/hepan.py`（基于 lunar-python，MIT） | 是，同一输入永远同一输出 |
| 规则层 | 真太阳时、夏令时、晚子时、边界提示（`scripts/solartime.py`） | 是，参数显式 |
| 解释层 | 十神、五行、格局、领域解读、时间窗 | 否，是假设，必须标注 |

## 独立使用，还是配合军师

| 模式 | 何时用 | 读什么 |
| --- | --- | --- |
| **独立模式（默认）** | 用户只问命理：性格、事业、财运、学业、家庭、时间窗 | 本文 + 对应领域文件；走完四段式即结束 |
| 协作模式（可选） | 用户问“该不该继续/怎么说/怎么推进” | 额外读 `03`、`06`，产出命理简报交给狗头军师 |

**独立模式不需要狗头军师**。只有当问题从“看清自己”变成“决定关系策略/话术”时，才建议交接。

## 加载顺序

1. 先读 `SKILL.md` 的“排盘流程”和“输出结构”，不要先读知识文件。
2. 判断问题属于哪个领域，读 **1–2 份**领域文件。
3. 涉及风险、伦理、危机：先读 `05-伦理边界与话术红黑线.md`。
4. 用户要求来源、证据等级或“这有什么依据”：读 `11`（古籍与文献）或 `12`（证据分级）。

## 领域路由

| 用户说 | 先做什么 | 读这份 | 越界禁区 |
| --- | --- | --- | --- |
| “我是什么命 / 我性格怎么样” | 排盘，四段式 | `02-十神-五行-格局读法.md` | 不下“身强身弱、用神喜忌”定论 |
| “适合什么工作 / 什么时候换工作 / 财运如何” | 排盘 + 大运 | `07-事业-财运-职业方向.md` | 不给行业/公司/投资标的 |
| “能不能考上 / 学什么专业 / 孩子学习” | 排盘 + 时间窗 | `08-学业-考试与专业选择.md` | 不预测分数、录取、上岸 |
| “我身体怎么样 / 最近很焦虑” | 排盘先降级 | `09-身心状态与健康边界.md` + `05` | 不诊断、不预测疾病、不劝停药 |
| “和父母/孩子为什么这么累 / 家庭关系” | 排盘 | `10-家庭六亲与代际关系.md` | 不断第三方寿元、健康、婚变 |
| “我俩合不合 / 什么时候有机会” | 两张盘 + `hepan.py` | `03-合盘与关系维度.md`、`06` | 不给“能不能成”的判决 |
| “最近很迷茫，什么时候能好” | 排盘 + 当前大运流年 | `04-大运流年与时间窗.md` | 不承诺具体应期 |
| “这有什么依据 / 古人怎么说” | 先给分级 | `11-古籍与文献索引.md`、`12-证据分级与现代研究.md` | 不把 D 级说成 A 级 |
| “给我一句话 / 一段经文 / 箴言” | 一条 + 出处 | `13-经文与格言.md` | 劝诱、恐吓、拿经文当预测 |
| “我这算不算克夫/命硬” | 先破标签 | `02`、`05` | 不承认污名标签 |
| “帮我改运/化解” | 拒绝 + 现实替代 | `05` | 不推销任何仪式 |

## 硬规则

- 不把 `wuxing.percent` 当旺衰定论。
- 不引用本 skill 之外的“大师说法”充当权威。
- 任何结论必须能指出盘面证据行；指不出来就不说。
- 计算层报错或依赖缺失时，明确说“现在排不了盘”，不要凭生日口算糊弄。
- 引用古籍时：标明书名与篇章，且说明“这是传统说法，不是实证结论”。
