# 事业、财运与职业方向

> 独立使用场景：用户问“我适合做什么工作 / 什么时候换工作 / 财运怎么样 / 能不能创业”。
> 结论一律是**提问角度 + 可验证假设**，不是职业测评，也不是投资建议。

## 一、盘面里能用的依据（及局限）

| 盘面 | 传统说法 | 可以讨论成什么 | 不能说什么 |
| --- | --- | --- | --- |
| 月令（月支） | 事业环境、格局所系 | 什么样的组织环境让人舒展（规则型/自主型/创意型） | “你命里当官/发财” |
| 官杀（正官/七杀） | 规则、责任、权威关系 | 能不能长期忍受被管理；压力下是硬扛还是绕开 | “七杀无制必凶” |
| 印星（正印/偏印） | 支持、学习、资质 | 更依赖体系与证书，还是靠自学与直觉 | “印旺必靠父母” |
| 食伤（食神/伤官） | 输出、表达、技艺 | 更适合做产品/内容/手艺，还是执行与协调 | “伤官见官必离职” |
| 财星（正财/偏财） | 资源、结果、交易 | 对回报敏不敏感；适合稳定收入还是浮动收入 | “财多身弱必破财” |
| 比劫 | 同辈、竞争、合伙 | 合伙的风险点：分账、边界、功劳归属 | “比劫旺必被朋友坑” |
| 五行偏重 | 行为语言 | 木=扩张、火=表达、土=稳定、金=规则、水=流动 | “缺什么补什么”“改运发财” |

**五行计数只是加权计数**，不是旺衰定论；不要输出“身强能担财、身弱不担财”这类专业判词。

## 二、可以给的四种东西

1. **工作风格假设**：在什么条件下效率高、什么条件下内耗（带盘面证据 + 反向可能）。
2. **组织形态匹配**：大公司/小团队/自雇/自由职业，各自的代价，不排序、不推荐具体公司。
3. **换工作的时间窗**：用大运流年做“外部主题”提示；同时给观察信号（投递反馈、面试节奏、offer 质量）。
4. **财务行为的提醒**：对风险与回报的偏好、冲动决策的触发点；不涉及具体标的。

## 三、红线

- 不给**具体行业/公司/岗位**的“你适合去 X”。
- 不给**投资标的**：股票、基金、币、彩票、房产买卖时点。
- 不说“你今年必升职/必被裁”“创业必成/必败”。
- 不把“财运差”当借口劝阻用户做正常决策（换工作、谈加薪、搬城市）。
- 不承诺“补财库、开财门、招财法事”。

## 四、输出模板

```text
盘面：月令申金（比肩），天干透甲木偏财、乙木正财；当前行辛巳大运（2018–2027）。
边界：时柱稳定，未命中夏令时；五行计数只作提示。
假设（不是定论）：你对“投入产出比”比较敏感，可能更适合能算清账的环境（项目制、提成制、合伙分成），
    长期在纯固定薪、评价标准模糊的组织里容易憋。
反向可能：也可能只是这几年做业务训练出来的习惯，换个环境会变。
时间窗（假设）：2027 换大运前后容易出现“想重新安排职业”的念头，适合复盘而不是立刻裸辞。
可验证的小动作：接下来一个月，记录你在哪些任务后最有“这事值”的感觉，再看它们是否都带明确的结果反馈。
```

## 五、常见误用

- 把“财星多”当“会发财”：财星是关系与资源的语言，不是收入预测。
- 把“官杀重”当“适合体制内”：还要看能不能承受规则与被评价。
- 用流年“破财”吓用户买化解服务。
- 把命理当职业测评：真正的职业选择要靠能力盘点、行业信息和试错。
