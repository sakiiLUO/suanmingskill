# 命理档案与交接协议

## 档案要存什么（最小集）

只存排盘必需字段。不存聊天原文、截图、对方评价、健康信息。

```json
{
  "schema": "suanming.profile.v1",
  "name": "我 / A / B",
  "gender": "male",
  "birth_clock": "1995-08-17 14:30",
  "city": "杭州",
  "longitude": 120.155,
  "tz_hours": 8.0,
  "dst_mode": "auto",
  "late_zi": "next_day",
  "pillars": {"year": "乙亥", "month": "甲申", "day": "庚辰", "time": "癸未"},
  "day_master": "庚金",
  "notes": "用户补充的一句话背景（可选）",
  "updated_at": "2026-10-25T16:00:00",
  "notice": "（本档案只保存排盘所需字段，不含聊天原文与截图）"
}
```

## 同意与撤销

```bash
# 保存（必须显式 --consent；不加就拒绝落盘）
python scripts/archive.py save --name A --json .suanming/a.json --consent

# 查看 / 列表 / 硬删除
python scripts/archive.py show --name A
python scripts/archive.py list
python scripts/archive.py delete --name A

# 改目录（默认工作区 .suanming/）
python scripts/archive.py list --dir D:\private\suanming
# 或设环境变量 SUANMING_ARCHIVE_DIR
```

- 首次保存前必须得到用户明确同意，并说明“存什么、存哪、怎么删”。
- 用户可随时要求查看、暂停、删除；删除是硬删除。
- 脚本不可用或写入失败时，诚实说“这次没有保存”，不要假装记住了。

## 与狗头军师的交接

### 谁读什么

| 数据 | 算命 | 军师 |
| --- | --- | --- |
| 四柱、十神、大运流年 | 生成并解释 | 只读简报，不自己推算 |
| 合盘 axes | 生成 | 读结论，转向策略 |
| 关系档案（军师侧） | 不读 | 自己维护 |
| 命理档案（本 skill 侧） | 自己维护 | 需要时读同一份 |

**不要双向同步**：两边各自维护自己的档案格式，只在对话里传“简报”，避免字段漂移。

### 简报格式（≤300 字）

```text
【命理简报·仅供讨论】
A：{日主}，月令{五行}，日支{支}；当前{大运干支}（{起止年}），{今年}流年{干支}。
B：同上。
合盘：{日主关系}；{日支关系}；{互补情况}；{流年同频情况}。
不确定：{时辰边界 / 夏令时 / 时辰不明 / 口径差异}。
性质：以上为提问角度，不是关系判断；现实互动优先。
```

### 交接时的分工句（直接说给用户听）

> 命理这部分我能给的是“你们容易在什么节奏上撞车、哪段时间外部压力偏大”；至于要不要继续、怎么开口、什么时候退，让军师那边给策略，我这边不越界。

## 冲突与降级

1. 简报与用户描述的现实行为矛盾 → 以行为为准，明说盘面解释不了。
2. 军师给的策略与命理时间窗冲突 → 以军师策略为准（现实互动优先）。
3. 依赖缺失/脚本报错 → 说“现在排不了盘”，不口算、不猜。
4. 用户不愿提供出生信息 → 不排盘，直接做非命理的情绪与关系支持。
