# 与狗头军师的配合协议

狗头军师（[goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi)，MIT）是一个 Codex/Claude Skill：先接住情绪，再拆事实，最后给可执行策略；知识库在 `references/knowledge` 与 `references/practical`，有可选的本地 SQLite 关系档案。

它和算命 skill 的形态高度一致（`SKILL.md` + 按需加载 references + scripts），所以配合方式也是**文档级 + 简报级**，不需要写插件、不需要互相调用 API。

## 一、职责边界（写死在两边）

| 主题 | 算命 | 军师 |
| --- | --- | --- |
| 四柱、十神、大运流年 | 计算并解释 | 只读简报，不推算 |
| 合盘维度 | 给维度、证据、置信度 | 给判断、策略、话术 |
| “合不合/能不能成” | 只回答“容易在哪儿撞车” | 回答“要不要推进、怎么推进” |
| 时间窗 | 给假设 + 观察信号 | 结合互动决定用不用 |
| 情绪、冲突、边界、安全 | 立即让位 | 主责 |
| 档案 | 命理档案（`archive.py`） | 关系档案（SQLite） |

**互不背书**：算命不说“军师说了算”，军师不复述命理结论当事实。

## 二、两种使用模式

### 模式 A：先算命，后军师（推荐）

1. 用户问“我们合不合 / 什么时候有机会”。
2. 算命 skill 排两张盘 → `hepan.py` → 输出四段式（盘面 / 边界 / 假设 / 动作）。
3. 末尾附【命理简报】。
4. 用户切到军师（或同一会话里军师被唤起），军师读简报，转向策略与话术。

### 模式 B：军师主流程中按需借盘

军师正在处理“要不要主动、怎么开口”，用户可以补一句“顺便看看我今年的运势”。此时：

- 只排当前用户的盘，**不为对方擅自排盘**（除非对方信息已由用户提供且知情）。
- 只输出与当前决策相关的一条时间窗假设，不展开性格长文，不打断军师的情绪流程。
- 交接句：“命理这边只给一个观察窗口，具体怎么做听军师的。”

## 三、简报格式（唯一交接物）

```text
【命理简报·仅供讨论】
A：庚金日主，月令申金，日支辰；行辛巳大运（2018–2027），2026 流年丙午。
B：甲木日主，月令卯木，日支辰；行乙酉大运（2022–2031），2026 流年丙午。
合盘：日主金克木（推动/施压倾向）；日支辰辰自刑（相处节奏易内耗）；
五行互补不明显；2026 双方流年同支巳巳。
不确定：A 出生时间距时辰边界 12 分钟，时柱可能变；B 未命中夏令时。
性质：以上为提问角度，不是关系判断；现实互动优先。
```

规则：≤300 字；只写盘面与维度；必须带“不确定”和“性质”两行；不写建议、不写“应该”。

## 四、冲突处理

| 冲突 | 处理 |
| --- | --- |
| 命理结论 vs 用户描述的行为 | **以行为为准**，明说“盘面解释不了这件事” |
| 命理时间窗 vs 军师策略 | 以军师为准（现实互动优先） |
| 两边都给“建议” | 算命停手，让军师收口 |
| 用户只信命理、拒绝看现实 | 军师接情绪；算命降低确定性表述，改为提问 |

## 五、档案不互通

- 算命档案：`archive.py`，JSON，字段最小化，需 `--consent`，可 `delete`。
- 军师档案：`scripts/memory_store.py`，SQLite，需首次同意，可撤销/暂停/硬删除。
- **不做双向同步**。两边各自维护；对话里只传简报。理由：字段语义不同，同步会漂移，也会扩大隐私面。

## 六、联合验收清单

- [ ] 单独问“我八字怎么样”，算命能排盘并给四段式，不越界给关系策略。
- [ ] 单独问“他这句话怎么回”，军师能直接给成品，不要求先排盘。
- [ ] 问“我俩合不合”，先出简报，再给策略，两段边界清楚。
- [ ] 用户说“我不想提供生日”，两个 skill 都不阻塞，直接做非命理支持。
- [ ] 用户描述家暴/自伤，两边都停止解读并转介。
- [ ] 用户说“帮我改运/化解”，算命拒绝并给现实替代。
