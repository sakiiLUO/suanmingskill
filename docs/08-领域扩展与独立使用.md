## 二、独立使用 vs 协作使用

| | 独立模式（默认） | 协作模式（可选） |
| --- | --- | --- |
| 触发 | 只问命理：性格/事业/学业/家庭/时间窗 | 问“该不该继续/怎么说/怎么推进” |
| 流程 | 排盘 → 四段式 → 结束 | 排盘 → 四段式 → 命理简报 → 军师 |
| 依赖 | 无 | 需要 goutoujunshi 已安装 |
| 交付物 | 假设 + 一个可验证动作 | 简报（≤300 字）+ 分工说明 |

**判断标准**：问题里出现“我/我该/我要不要”是独立模式；出现“他/她/我们/怎么回/怎么推进”且用户想要策略，才进入协作模式。

## 三、领域路由的实现方式

不是靠分类器，而是靠 SKILL.md 的一张表 + 每条领域的“只给/不给”清单：

| 领域 | 只给 | 不给 |
| --- | --- | --- |
| 性格 | 2–3 条带证据的假设 + 反向可能 | 身强身弱、用神喜忌定论 |
| 事业/财运 | 工作风格、组织形态、时间窗 | 具体行业/公司/投资标的 |
| 学业 | 学习方式、压力节奏 | 分数、录取、上岸概率 |
| 身心 | 压力反应、作息、求助路径 | 诊断、疾病预测、停药 |
| 家庭 | 角色模式、边界议题 | 第三方寿元/健康/婚变 |
| 关系 | 7 维度 + 证据 + 简报 | “能不能成”的判决 |

一次只答一个领域；多领域提问时先答最急的，其余一句话带过。

## 四、古籍与文献怎么用

1. **只用公有领域原文**：宋明清古籍（《渊海子平》《三命通会》《滴天髓》《穷通宝鉴》《子平真诠》《神峰通考》）作者均已过世数百年，可引用；现代点校本、白话译注、他人断语库有版权，不复制。
2. **引用格式**：书名 + 篇章 + 原文；并加一句“这是传统说法，不是实证结论”。
3. **不把古籍当权威判决**：古籍内部流派冲突很大（如子平 vs 神峰的病药说），引用时要说明是哪一派。
4. **原文必须核对**：本 skill 的 `references/11` 只收录实际抓取到的原文（附来源链接）；抓不到的只列书目，不补写。
5. **证据分级**见 `references/12`：命理内容默认 D 级（师承经验/流行说法），古籍属 C 级（理论框架），实证研究才可能到 A/B。**不能把 D 级包装成 A 级。**

## 五、新增边界（相对 v1 收紧）

- **健康**：不诊断、不预测疾病、不建议停药；症状一律导向就医。
- **投资**：不给标的、不给买卖时点、不预测涨跌。
- **学业**：不预测分数/录取/上岸；不给孩子贴“不是读书的料”。
- **第三方**：不分析父母/配偶/子女的健康、寿元、婚变、子女数量。
- **古籍引用**：不伪造原文；不确定就只给书目。

## 六、验证方式

1. `validate_skill.py` 会检查 SKILL.md 引用的每份 references 是否存在（本次扩展中它确实拦住了两个尚未创建的文件）。
2. 现有 52 个测试继续通过（领域扩展不改变计算层与规则层）。
3. 新增人工检查：领域路由表每行都有“只给/不给”，确保没有领域漏掉边界。
4. 后续建议：为每个领域补 2–3 条对话红队用例（如“我该不该辞职”“能不能考上”“我妈还能活多久”）。

## 七、为什么不做成“一个万能大师”

- 命理的强项是**结构化的自我描述与提问角度**，不是预测具体事件；铺得越宽越容易滑向“什么都能算”。
- 每个领域都有现实更强的信息源（职业测评、招聘信息、医生、老师、律师）。命理的位置是**补充视角**，不是替代。
- 领域边界写清楚，用户才不会把“他说我适合创业”当成决策依据。
